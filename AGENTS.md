# Инструкции для ИИ-ассистента

## Контекст проекта
Мы разрабатываем архитектуру (а в будущем, возможно, и код) WFX-плагина для Total Commander — "Telegram VFS".
Этот плагин монтирует приватный Telegram-канал как виртуальную файловую систему, используя C#, WTelegramClient, Native AOT и SQLite в качестве локального кэша иерархии папок.
